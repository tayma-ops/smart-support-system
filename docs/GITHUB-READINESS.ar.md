## الأمان وما رُفع

فُحصت **كل محتويات Git index للملفات الـ130** قبل أول commit، بما فيها الترجمة الثنائية: لم توجد القيم الخاصة الفعلية أو كلمات مرور العرض الأربع أو أنماط مفاتيح خاصة وتوكنات شائعة. أُكد تجاهل الملفات الخاصة وعدم وجودها في index.

رُفع المصدر والقوالب والأصول والترجمة والاختبارات والاعتماديات وملفات Docker وCI والوثائق. القائمة الكاملة: [FILES.md](FILES.md).

لم تُرفع `.env` أو `.local/` أو بيانات PostgreSQL/Redis أو قواعد SQLite أو كلمات المرور أو النموذج وأدواته أو venv أو logs أو caches أو وسائط الرفع. `.env.example` فقط مشمول بقيم أسرار فارغة. بيانات CI والاختبارات الثابتة بيانات اختبار معلنة ومعزولة، وليست بيانات التشغيل أو حساباتك. هذا فحص للقيم المعروفة والأنماط الشائعة، وليس ضمانًا عامًا لاكتشاف كل سر محتمل مستقبلًا.

أُبقيت الحسابات الأربعة والأقسام الخمسة والتذاكر الـ12 والردود التسعة والأحداث الـ12 وبصمات كلمات المرور دون تغيير خلال التحقق المحلي. تبقى النسخ والبيانات الخاصة على الجهاز ومستثناة من Git.

## الاستكمال البرمجي المنفذ قبل النشر

- إصلاح صفحة دخول الإدارة للزائر، وعدادات محاولات المصادقة، ورفض تجديد JWT بعد تغيير كلمة المرور أو حذف الحساب.
- إصلاح إسناد الموظف لتذكرته في قسم آخر: لا زر غير صالح، ورفض الطلب غير المؤهل، ومعالجة تغير العضوية برسالة بدل خطأ 500؛ أُضيفت ثلاثة اختبارات انحدار.
- تحقق HTTP فعلي من إنشاء التذكرة وتحليل محلي حقيقي دون رد تلقائي، والإسناد والملاحظات الداخلية وإخفائها عن العميل، ثم الإرسال الصريح وقراءة الرد عبر REST والحل والإغلاق وإعادة الفتح.
- تحسين تنقل الهاتف بلوحة المفاتيح وأنواع الأزرار والعناصر الزخرفية، مع إبقاء العربية وRTL ورسائل التحقق.
- تثبيت اعتماديات التشغيل والتطوير من المصدر في بيئة جديدة، ومراجعة README وملفات الأمان والمساهمة والترخيص والاستثناءات. لم يُعد بناء المشروع أو تُحذف PostgreSQL أو Redis أو Celery أو AI.

## ما بقي خارج التحقق

- صور حقيقية وفحص بصري للهاتف والتابلت والكمبيوتر: أدوات المتصفح لم تكن متاحة. لا صور وهمية ولا ادعاء بأن اختبارات HTTP بديل عن الفحص البصري.
- OpenAI السحابي والبريد الخارجي: لا مفاتيح/حسابات حقيقية قُدمت؛ المحلي وSMTP sink مختبران.
- نشر التطبيق للعامة، واختبارات الحمل والأمان المستقلة، وتقييم إحصائي لجودة النموذج الصغير. GitHub هنا استضافة للمصدر، وليس رابط تطبيق منشور.
