## المعلومات الحساسة وGitignore

توجد أسرار لازمة للتشغيل **على الجهاز** في `.env` وداخل `.local/`؛ لا تدخل قائمة المصدر المرشحة للرفع. فحص ملفات التسليم الـ**130**، بما فيها ملفات الترجمة الثنائية، لم يجد القيم الخاصة الفعلية أو كلمات مرور العرض الأربع أو تطابقًا مع أنماط مفاتيح خاصة وتوكنات شائعة. لا توجد commits سابقة في هذا المستودع ولا remote مضاف وقت المراجعة.

أسماء مثل `SECRET_KEY` و`AI_API_KEY` موجودة طبيعيًا في الكود و`.env.example`، لكن المثال يترك قيم الأسرار فارغة. قيم CI وكلمات مرور الاختبارات الثابتة بيانات اختبار معلنة ومعزولة، وليست بيانات حساباتك أو بيئة التشغيل.

| ستدخل المصدر عند `git add .` | ستُستبعد وفق الفحص الحالي |
| --- | --- |
| README وLICENSE وSECURITY وCONTRIBUTING وملفات الإعداد الآمنة | `.env` و`.env.*` مع استثناء `.env.example` الآمن |
| تطبيقات Django وmigrations وtests وscripts | `.local/`، بيانات PostgreSQL/Redis المحمولة، النموذج وأدواته والنسخ والبيانات الخاصة |
| templates وCSS وJavaScript وSVG وترجمة العربية | `.venv/` و`venv/` و`__pycache__/` وملفات Python المترجمة وcaches |
| requirements وDockerfile وCompose وCI | SQLite وقواعد التطوير المحلية وملفات dump/backup والمفاتيح والشهادات الخاصة |
| docs وخطة screenshots؛ الصور الحقيقية عند إضافتها | `.idea/` و`.vscode/` و`.vs/` والملفات المؤقتة وlogs وPID وملفات beat المحلية |

تم اختبار قواعد التجاهل حتى للملفات غير الموجودة مثل مفتاح خاص أو صورة Screenshot مستقبلية: الأسرار مستبعدة، بينما migrations والصور داخل `docs/screenshots/` لا تُستبعد. كذلك لم يُعثر على ملف موجود في فهرس Git وتطابقه قاعدة تجاهل خاصة. فحص الأسرار هنا خاص بالمحتوى الحالي والقيم المعروفة، وليس ضمانًا عامًا بأن أي محتوى تضيفه مستقبلًا آمن.
